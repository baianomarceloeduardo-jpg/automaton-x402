WHAT THIS IS
------------
A zero-dependency Node.js HTTP API that sells compute for USDC on Base using
x402-style pay-per-call. Payment IS authentication: unpaid calls get HTTP 402
with machine-readable terms; paying calls are verified on-chain and served.

PRODUCT LINES
-------------
A) Utilities (0.001 USDC/call)
   /v1/hash?input=   SHA-256 hex of input
   /v1/echo?msg=     echo + server time
   /v1/uuid          UUIDv4
   /v1/random?min=&max=  CSPRNG integer in range
B) Attestation Ledger (0.001 USDC/call)  <-- the non-commodity product
   /v2/attest?data=  (GET) or POST {"data":...}
     -> appends a SIGNED, HASH-CHAINED entry to an append-only ledger and
        returns it. Entry = {index, prevHash, timestamp, dataHash, hash,
        signature, keyId}. hash = sha256(prevHash|timestamp|dataHash);
        signature = ECDSA-P256-SHA256 over hash.
   FREE public auditability:
     /v2/pubkey                 public key (PEM) + keyId
     /v2/verify?index=N         recompute hash + signature + chain link
     /v2/verify?dataHash=...    find + verify by data hash
     /v2/ledger?from=&limit=    read the chain
   Rationale: any caller can hash a string; only a persistent signing authority
   can issue a verifiable attestation bound to a time and chained to history.
   That cannot be replicated by the caller -> genuine value.

3. Client retries SAME request with header X-PAYMENT: <txHash>.
4. Server verifies via Base JSON-RPC (mainnet.base.org):
